# المرحلة 5–6: الصور + التدقيق الهندسي المستقل

> **قاعدة ملزمة:** الصور المولدة بالذكاء الاصطناعي **ليست** ملف CAD ولا STL. لا يُعلن أي منتج «قابلاً للطباعة للبيع» قبل نموذج CAD حقيقي + فحص سماكات + اختبار خلوص + نموذج أولي على X1C وA1.

**الألوان المستخدمة في التصور:** Lapis Blue، Sandstone Beige، Matte Charcoal، Ivory، Warm Gold للتفاصيل فقط.

**مسار الصور:** `docs/product-catalog/v2/renders/`

## المنتج A — بوابة عشتار المنزلقة (`#2`)

### ملفات الصور
| الملف | المحتوى |
|---|---|
| `v2-01-ishtar-slider-orthographic.png` | أمامي/خلفي/جانبي/علوي/منظور مركّب |
| `v2-01-ishtar-slider-exploded-section.png` | Exploded + مقطع داخلي + حركة |
| `v2-01-ishtar-slider-in-use.png` | أثناء الاستخدام |

### تدقيق هندسي مستقل

| فحص | النتيجة | ملاحظة |
|---|---|---|
| تطابق Exploded مع المركّب | **تحذير** | بعض الرندرات تُظهر إطارات أبراج أعلى من المواصفات 14 مم سماكة — يجب كبح الارتفاع الزخرفي في CAD |
| عدد الأجزاء = 5 | **تحذير** | التأكد أن الغطاء الخلفي اختياري أو إلزامي؛ لا أجزاء ذهبية إضافية غير مدرجة |
| قابلية طباعة كل جزء | **مقبول مبدئياً** | كل القطع مسطحة الاتجاه |
| اتجاه الطباعة | أفقي على الوجه الكبير | يقلل الدعم إلى صفر |
| زوايا تحتاج دعم | لا إن قنوات مفتوحة من الأعلى ثم تُغلق بغطاء | إن طُبعت PiP بالكامل قد تندمج الصفوف |
| أجزاء معرّضة للكسر | مقابض الصفوف إن <2 مم | جعل المقبض ≥2.4×8 مم |
| سماكات الجدران | الإطار يجب ≥2.4 مم | الشبكة/الرموز ≥0.8 بارز |
| خلوص الحركة | هدف 0.40 مم | طباعة عينات 0.35/0.40/0.45 |
| ثبات القاعدة | جيد (قطعة مكتبية منخفضة) | — |
| سهولة التجميع | جيدة إن كانت صفوفاً تُدخل من الطرف | أضف تشطيب دخول مشطوف 30° |
| إلكترونيات | لا يوجد | — |
| AMS | لا — ألوان كقطع | ممتاز |
| نوزل 0.4 | نعم | رموز لا أضيق من 0.8 مم |
| واقعية الوقت/الوزن | ~1س45د / ~32غ | واقعي على X1C |
| دقة تاريخية | رموز هندسية مبسّطة | لا نسخ حرفية لثيران برغامون |
| ملكية فكرية | تصميم أصلي مطلوب | لا اشتقاق من ملفات SDFL |
| ملاءمة البيع | عالية جداً | — |

### القرار
**يحتاج تعديلات محددة** قبل CAD النهائي، ثم صالح للانتقال إلى CAD بعد:
1. تثبيت السماكة الإجمالية ≤18 مم إن أُضيفت أبراج، أو إبقاء الجسم 14 مم والأبراج كتضاريس ≤4 مم.  
2. قنوات مفتوحة من الخلف + غطاء (أوثق من PiP كامل للمبتدئ).  
3. إزالة أي زخارف غير مذكورة في قائمة الأجزاء الخمس.  
4. نموذج أولي بثلاثة خلوصات.

## المنتج B — الختم الأسطواني الشخصي (`#21`)

### ملفات الصور
| الملف | المحتوى |
|---|---|
| `v2-02-cylinder-seal-orthographic.png` | مساقط + مركّب |
| `v2-02-cylinder-seal-exploded-section.png` | Exploded + مقطع + دحرجة |
| `v2-02-cylinder-seal-in-use.png` | أثناء الدحرجة على صلصال |

### تدقيق هندسي مستقل

| فحص | النتيجة | ملاحظة |
|---|---|---|
| تطابق Exploded مع المركّب | **مقبول** | 4 أجزاء واضحة |
| عدد الأجزاء = 4 | **مقبول** | أسطوانة، محور، قلنسوة اسم، حامل |
| قابلية طباعة النقش | **تحذير جوهري** | FDM 0.4 صعب للنقش الغائر الدقيق؛ يلزم عمق ≥0.7 وعرض خط ≥0.8 |
| اتجاه الطباعة | الأسطوانة **عمودية** أفضل للنقش المحيطي المتسق أو أفقية مع دعم صفري إذا كان النقش بارزاً كافياً | يُختبر الاتجاهان |
| دعم | لا | — |
| كسر | المحور Ø8 مقبول؛ لا تجعل النقش يضعف الجدار تحت 2 مم | جدار الأسطوانة ≥2.4 |
| خلوص | قبضة/محور 0.15–0.20 تركيب ثابت | لا حركة حرة مفرطة |
| ثبات الحامل | مقبول | قاعدة ≥60×40 |
| تخصيص الاسم | قلنسوة منفصلة | حروف عربية ≥1.0 مم ارتفاع و≥1.2 عرض قلم |
| مسماري | **إلزامي** | بطاقة: «زخرفة مستوحاة من الخط المسماري» — الاسم الحقيقي على القلنسوة فقط |
| وقت/وزن | ~1س40د / ~28غ | واقعي |
| ملكية فكرية | لا تنسخ أختام متحف حرفياً | زخارف هندسية أصلية |
| طين/طعام | صلصال أطفال/اصطناعي فقط | لا ادعاء ملامسة غذائية |

### القرار
**يحتاج تعديلات محددة**، ثم **صالح للانتقال إلى CAD**:
1. ملف بارامتري للأسماء (عربي/كردي/لاتيني).  
2. مكتبة 3 نقوش هندسية أصلية فقط (لا نسخ MET/Penn).  
3. اختبار وضوح الانطباع على صلصال بعد الطباعة.  
4. إن فشل وضوح النقش الغائر → التحويل إلى نقش بارز عميق للدحرجة على عجينة ناعمة جداً أو بيعه كختم حبر مكتبي بديل.

## المنتج C — شناشيل المفاتيح (`#12`)

### ملفات الصور
| الملف | المحتوى |
|---|---|
| `v2-03-shanasheel-keys-orthographic.png` | مساقط + مركّب |
| `v2-03-shanasheel-keys-exploded-section.png` | Exploded + مقطع + حركة درج |
| `v2-03-shanasheel-keys-in-use.png` | مفاتيح معلّقة + درج موارب |

### تدقيق هندسي مستقل

| فحص | النتيجة | ملاحظة |
|---|---|---|
| تطابق Exploded مع المركّب | **تحذير** | بعض الصور تضيف أدراجاً/مقصورات إضافية غير موجودة في قائمة 7 أجزاء — **يُمنع** إدخالها في CAD |
| عدد الأجزاء = 7 | يجب تثبيته في CAD كـ: هيكل، شبكة، درج، خطاف×4 **أو** هيكل، شبكة، درج، سكة، خطاف×3 | اختر تفصيلاً واحداً وثبّته |
| طباعة الشبكة | **تحذير** | كل ضلع ≥1.6 مم؛ فتحات ≥3 مم |
| اتجاه | الهيكل ظهره على السرير | بدون دعم |
| درج | خلوص 0.35 جانبي؛ سكة ≥2 مم | منع التواء بضلع سفلي |
| خطافات | جذر ≥3×6 مم | اختبار 80 غ لكل خطاف |
| مغناطيس اختياري | جيب +0.20 مم | pause-at-height |
| ثبات جداري | ثقبا تعليق ≥5 مم | قالب مسافات براغي |
| AMS | لا | شبكة بلون منفصل تُركّب |
| وقت/وزن | ~6س15د / ~145غ | مقبول لمنتج منزلي |
| تاريخي | شناشيل هندسية عامة | لا نسخ واجهة بيت محدد |
| بيع | عالٍ في أربيل | بيوت جديدة |

### القرار
**يحتاج تعديلات محددة**:
1. تجميد قائمة الأجزاء السبعة بلا إضافات من الرندر.  
2. تبسيط الشبكة إلى نمط واحد قابل للطباعة.  
3. نسخة جدارية فقط للإطلاق الأول (إزالة أي وضع مكتب إن زاد التعقيد).  
4. بعد ذلك: **صالح للانتقال إلى CAD**.
